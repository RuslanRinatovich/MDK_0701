# 🧪 Практическая работа №27  
## Создание задания: резервное копирование по расписанию

⏱️ **Продолжительность:** 90 минут  
🎯 **Цель работы:**  
Научиться создавать задания SQL Server Agent для автоматизации резервного копирования, настраивать многошаговые процессы, расписания и уведомления, а также управлять историей выполнения заданий.

🖥️ **Оборудование:**  
Виртуальная машина с Windows Server / Windows 10, установленными SQL Server Developer Edition и SSMS.

## 🧠 Глубокое погружение: перед началом

В этой работе вы создадите задание для автоматического резервного копирования. Задание будет:
1. Создавать полную резервную копию
2. Создавать разностную копию (на следующих шагах)
3. Очищать старые бэкапы
4. Отправлять уведомление при ошибке

В результате вы получите готовый инструмент для автоматизации бэкапов на своём сервере.

## 📋 Ход выполнения работы

### 🔹 Этап 1. Подготовка среды (10 мин)

1. Запустите **SSMS** и подключитесь к экземпляру SQL Server.

2. Убедитесь, что SQL Server Agent запущен:

```sql
-- Проверка статуса SQL Agent
EXEC xp_servicecontrol 'QUERYSTATE', 'SQLSERVERAGENT';
```

Если Agent не запущен, запустите его через **SQL Server Configuration Manager** или в обозревателе объектов SSMS.

3. Создайте тестовую базу данных:

```sql
CREATE DATABASE JobBackupPractice_Фамилия;
GO
USE JobBackupPractice_Фамилия;
GO

CREATE TABLE dbo.TestData (
    ID INT IDENTITY(1,1) PRIMARY KEY,
    Value NVARCHAR(100),
    Created DATETIME DEFAULT GETDATE()
);

INSERT INTO dbo.TestData (Value)
SELECT TOP 100 'Data ' + CAST(ROW_NUMBER() OVER (ORDER BY (SELECT NULL)) AS NVARCHAR)
FROM sys.objects a CROSS JOIN sys.objects b;
GO
```

4. Убедитесь, что модель восстановления FULL:

```sql
ALTER DATABASE JobBackupPractice_Фамилия SET RECOVERY FULL;
```

5. Создайте папку для бэкапов:

```sql
EXEC xp_cmdshell 'mkdir C:\Backup\ПР27\';
EXEC xp_cmdshell 'mkdir C:\Backup\ПР27\Full';
EXEC xp_cmdshell 'mkdir C:\Backup\ПР27\Diff';
EXEC xp_cmdshell 'mkdir C:\Backup\ПР27\Log';
```

6. **Сделайте скриншот** создания базы и папок.

---

### 🔹 Этап 2. Создание первого шага: полный бэкап (15 мин)

2.1. **В обозревателе объектов** перейдите к **SQL Server Agent → Jobs**

2.2. **ПКМ → New Job**

2.3. **На вкладке General:**
- **Name:** `DailyBackup_Фамилия`
- **Owner:** `sa`
- **Description:** `Автоматическое резервное копирование базы JobBackupPractice_Фамилия`

2.4. **На вкладке Steps → New:**
- **Step name:** `Full Backup`
- **Type:** `T-SQL script`
- **Database:** `master`
- **Command:**
```sql
DECLARE @FileName NVARCHAR(500);
SET @FileName = 'C:\Backup\ПР27\Full\JobBackupPractice_Фамилия_Full_' + 
                FORMAT(GETDATE(), 'yyyyMMdd_HHmm') + '.bak';

BACKUP DATABASE [JobBackupPractice_Фамилия]
TO DISK = @FileName
WITH COMPRESSION, CHECKSUM, STATS = 10;

IF @@ERROR != 0
BEGIN
    RAISERROR('Полный бэкап не удался', 16, 1);
END
```

- **On success action:** `Go to next step`
- **On failure action:** `Quit the job reporting failure`
- **Retry attempts:** `1`
- **Retry interval (min):** `5`

2.5. **Сделайте скриншот** вкладки с настройками шага.

---

### 🔹 Этап 3. Добавление второго шага: разностный бэкап (15 мин)

3.1. **На вкладке Steps → New:**
- **Step name:** `Differential Backup`
- **Type:** `T-SQL script`
- **Database:** `master`
- **Command:**
```sql
DECLARE @FileName NVARCHAR(500);
SET @FileName = 'C:\Backup\ПР27\Diff\JobBackupPractice_Фамилия_Diff_' + 
                FORMAT(GETDATE(), 'yyyyMMdd_HHmm') + '.bak';

BACKUP DATABASE [JobBackupPractice_Фамилия]
TO DISK = @FileName
WITH DIFFERENTIAL, COMPRESSION, CHECKSUM, STATS = 10;

IF @@ERROR != 0
BEGIN
    RAISERROR('Разностный бэкап не удался', 16, 1);
END
```

- **On success action:** `Go to next step`
- **On failure action:** `Quit the job reporting failure`

3.2. **Сделайте скриншот** настройки второго шага.

---

### 🔹 Этап 4. Добавление третьего шага: очистка старых бэкапов (15 мин)

4.1. **На вкладке Steps → New:**
- **Step name:** `Cleanup Old Backups`
- **Type:** `T-SQL script`
- **Database:** `master`
- **Command:**
```sql
-- Удаление бэкапов старше 7 дней
DECLARE @DeleteCommand NVARCHAR(500);
SET @DeleteCommand = 'forfiles /p "C:\Backup\ПР27\Full" /m *.bak /d -7 /c "cmd /c del @file"';
EXEC xp_cmdshell @DeleteCommand;

SET @DeleteCommand = 'forfiles /p "C:\Backup\ПР27\Diff" /m *.bak /d -7 /c "cmd /c del @file"';
EXEC xp_cmdshell @DeleteCommand;

SET @DeleteCommand = 'forfiles /p "C:\Backup\ПР27\Log" /m *.trn /d -7 /c "cmd /c del @file"';
EXEC xp_cmdshell @DeleteCommand;

PRINT 'Очистка завершена';
```

- **On success action:** `Quit the job reporting success`
- **On failure action:** `Quit the job reporting failure`

4.2. **Если xp_cmdshell отключён**, используйте альтернативную команду:

```sql
-- Использование OLE Automation (если включено)
DECLARE @DateLimit DATETIME = DATEADD(day, -7, GETDATE());
EXEC master.dbo.xp_delete_file 
    @file_type = 0,
    @folder_path = 'C:\Backup\ПР27\Full',
    @extension = 'bak',
    @date_older = @DateLimit;
```

4.3. **Сделайте скриншот** настройки третьего шага.

---

### 🔹 Этап 5. Настройка расписания (15 мин)

5.1. **На вкладке Schedules → New:**
- **Name:** `DailySchedule`
- **Schedule type:** `Recurring`
- **Occurs:** `Daily`
- **Recurs every:** `1` `day(s)`
- **Occurs once at:** `02:00:00`
- Поставьте галочку **Enabled**

5.2. **Сделайте скриншот** настройки расписания.

5.3. **Создайте ещё одно расписание для разностного бэкапа:**

- **Name:** `HourlySchedule`
- **Occurs:** `Daily`
- **Recurs every:** `1` `day(s)`
- **Occurs every:** `1` `hour(s)` starting at `08:00:00` ending at `20:00:00`

5.4. **Сделайте скриншот** второго расписания.

---

### 🔹 Этап 6. Настройка уведомлений и запуск (20 мин)

6.1. **На вкладке Notifications:**
- **Event log:** Включить `When the job fails`
- **Email:** Выберите оператора (если настроен Database Mail)

6.2. **Создайте оператора для Email (если не создан):**

```sql
-- Если Database Mail настроен
EXEC msdb.dbo.sp_add_operator
    @name = N'DBA_Operator',
    @email_address = N'student@mail.ru';  -- Замените на свой email
```

6.3. **Нажмите OK** для создания задания.

6.4. **Запустите задание вручную для проверки:**

```sql
EXEC msdb.dbo.sp_start_job @job_name = N'DailyBackup_Фамилия';
```

6.5. **Проверьте историю выполнения:**

```sql
SELECT 
    j.name AS JobName,
    jh.run_date,
    jh.run_time,
    CASE jh.run_status
        WHEN 0 THEN '❌ Ошибка'
        WHEN 1 THEN '✅ Успех'
        WHEN 2 THEN '🔄 Повтор'
        WHEN 3 THEN '⏹️ Отменён'
        WHEN 4 THEN '⏳ Выполняется'
    END AS Status,
    jh.message
FROM msdb.dbo.sysjobs j
JOIN msdb.dbo.sysjobhistory jh ON j.job_id = jh.job_id
WHERE j.name = N'DailyBackup_Фамилия'
ORDER BY jh.run_date DESC, jh.run_time DESC;
```

6.6. **Проверьте созданные файлы:**

```sql
EXEC xp_cmdshell 'dir C:\Backup\ПР27\Full\*.bak';
EXEC xp_cmdshell 'dir C:\Backup\ПР27\Diff\*.bak';
```

6.7. **Сделайте скриншот** истории выполнения.

## 💡 Полезные советы

### Если SQL Agent не запущен:
- В SSMS: правой кнопкой на SQL Server Agent → Start
- Или через SQL Server Configuration Manager

### Если xp_cmdshell отключён:
- Включите для выполнения очистки (или используйте альтернативную команду):
```sql
EXEC sp_configure 'show advanced options', 1;
RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1;
RECONFIGURE;
```

- Запустите вручную через `sp_start_job`
- Проверьте историю в `sysjobhistory`
