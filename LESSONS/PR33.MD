# 🧪 Практическая работа №33  
## Настройка алерта на ошибку 825 (повтор чтения)

⏱️ **Продолжительность:** 90 минут  
🎯 **Цель работы:**  
Научиться настраивать алерты в SQL Server Agent на конкретную ошибку, создавать операторов, настраивать уведомления (включая эмуляцию email) и тестировать срабатывание алерта.

🖥️ **Оборудование:**  
Виртуальная машина с Windows Server / Windows 10, установленными SQL Server Developer Edition и SSMS.

---

## 🧠 Глубокое погружение: перед началом

В этой работе вы создадите алерт на ошибку 825 — предупреждение о проблемах с диском. В учебной среде сложно естественным образом вызвать ошибку 825, поэтому мы смоделируем её с помощью недокументированных методов (например, использование DBCC WRITEPAGE в тестовой среде) или просто протестируем с другой ошибкой (например, 823 с повреждённым файлом). Но понимание настройки останется полным.

## 📋 Ход выполнения работы

### 🔹 Этап 1. Подготовка среды (10 мин)

1. Запустите **SSMS** и подключитесь к экземпляру.

2. Убедитесь, что SQL Server Agent запущен.

3. Создайте таблицу для эмуляции лога ошибок:

```sql
CREATE DATABASE AlertLog_Фамилия;
GO
USE AlertLog_Фамилия;
GO

CREATE TABLE dbo.ErrorLog (
    LogID INT IDENTITY(1,1) PRIMARY KEY,
    ErrorNumber INT,
    ErrorMessage NVARCHAR(1000),
    ErrorTime DATETIME DEFAULT GETDATE(),
    AlertName NVARCHAR(100)
);
```

4. Создайте папку для файлов (опционально):

```sql
EXEC xp_cmdshell 'mkdir C:\AlertTest\';
```

5. **Сделайте скриншот** создания базы и таблицы.

### 🔹 Этап 2. Создание оператора (Email) (10 мин)

2.1. **Создайте оператора** (если ещё не создан):

```sql
USE msdb;
GO

IF NOT EXISTS (SELECT 1 FROM msdb.dbo.sysoperators WHERE name = 'DBA_Team_Фамилия')
BEGIN
    EXEC dbo.sp_add_operator
        @name = N'DBA_Team_Фамилия',
        @email_address = N'dba_team@fakecompany.com',
        @enabled = 1;
    PRINT 'Оператор создан';
END
ELSE
    PRINT 'Оператор уже существует';
```

2.2. **Проверьте** создание:

```sql

```

### 🔹 Этап 3. Создание алерта на ошибку 825 (15 мин)

3.1. **Создайте алерт** через T-SQL:

```sql
USE msdb;
GO

-- Удаляем старый алерт, если существует
IF EXISTS (SELECT 1 FROM msdb.dbo.sysalerts WHERE name = 'Alert_825_Фамилия')
    EXEC dbo.sp_delete_alert @name = N'Alert_825_Фамилия';

-- Создаём новый алерт
EXEC dbo.sp_add_alert
    @name = N'Alert_825_Фамилия',
    @message_id = 825,
    @severity = 0,
    @enabled = 1,
    @delay_between_responses = 60,   -- не чаще раза в минуту
    @include_event_description_in = 1,
    @category_name = N'[Uncategorized]';

-- Добавляем уведомление оператору
EXEC dbo.sp_add_notification
    @alert_name = N'Alert_825_Фамилия',
    @operator_name = N'DBA_Team_Фамилия',
    @notification_method = 1;  -- email
```

3.2. **Проверьте** создание алерта:

```sql
SELECT name, message_id, severity, enabled, occurrence_count, last_occurrence_date
FROM msdb.dbo.sysalerts
WHERE name = 'Alert_825_Фамилия';
```

3.3. **Сделайте скриншот** результатов.

### 🔹 Этап 4. Создание задания, которое будет логировать срабатывание (15 мин)

4.1. **Создайте задание**, которое будет запускаться при срабатывании алерта:

```sql
USE msdb;
GO

DECLARE @jobId BINARY(16);

EXEC dbo.sp_add_job
    @job_name = N'Job_LogError825_Фамилия',
    @enabled = 1,
    @description = N'Логирование ошибки 825 в таблицу',
    @owner_login_name = N'sa',
    @job_id = @jobId OUTPUT;

EXEC dbo.sp_add_jobstep
    @job_id = @jobId,
    @step_name = N'Insert into log',
    @subsystem = N'TSQL',
    @command = N'
        INSERT INTO AlertLog_Фамилия.dbo.ErrorLog (ErrorNumber, ErrorMessage, AlertName)
        VALUES (825, ''Сработал алерт на ошибку 825 (проблемы с диском)'', ''Alert_825_Фамилия'');
    ',
    @database_name = N'AlertLog_Фамилия',
    @on_success_action = 3,
    @on_fail_action = 4;

EXEC dbo.sp_add_jobserver
    @job_name = N'Job_LogError825_Фамилия';
```

4.2. **Назначьте задание алерту**:

```sql
EXEC msdb.dbo.sp_update_alert
    @name = N'Alert_825_Фамилия',
    @job_name = N'Job_LogError825_Фамилия';
```

4.3. **Сделайте скриншот** назначения задания.

### 🔹 Этап 5. Эмуляция ошибки 825 (или альтернативной) для проверки алерта (20 мин)

**В учебной среде сложно естественным образом вызвать ошибку 825, поэтому:**

#### Вариант А (предпочтительный — для демонстрации логики):
Создайте алерт на более простую ошибку, которую можно вызвать гарантированно, например, **17806** (ошибка соединения) или **208** (неверное имя таблицы).

```sql
-- Создаём алерт на ошибку 208 (неверное имя таблицы)
EXEC msdb.dbo.sp_add_alert
    @name = N'Alert_208_Фамилия',
    @message_id = 208,
    @severity = 0,
    @enabled = 1,
    @delay_between_responses = 10;

-- Привязка оператора
EXEC msdb.dbo.sp_add_notification
    @alert_name = N'Alert_208_Фамилия',
    @operator_name = N'DBA_Team_Фамилия',
    @notification_method = 1;

-- Вызов ошибки 208
SELECT * FROM NonExistentTable;
```

#### Вариант Б (для ошибки 825 — сложный, только если есть возможность):
Повреждение страницы в тестовой базе (с помощью DBCC WRITEPAGE, только в учебных целях).

```sql
-- Альтернатива: Имитация ошибки 825 через DBCC WRITEPAGE
-- !!! ТОЛЬКО НА ТЕСТОВОЙ БД !!!
ALTER DATABASE AlertLog_Фамилия SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
DBCC WRITEPAGE ('AlertLog_Фамилия', 1, 1, 100, 0xAA, 1);
ALTER DATABASE AlertLog_Фамилия SET MULTI_USER;
```

5.1. **Создайте временную ошибку для проверки (ошибка 208)**:

```sql
-- Генерация ошибки 208
SELECT * FROM ThisTableDoesNotExist;
```

5.2. **Проверьте журнал ошибок**:

```sql
EXEC xp_readerrorlog 0, 1, '208';
```

5.3. **Проверьте, сработал ли алерт (при создании на 208):**

```sql
SELECT name, occurrence_count, last_occurrence_date
FROM msdb.dbo.sysalerts
WHERE name IN ('Alert_825_Фамилия', 'Alert_208_Фамилия');
```

5.4. **Проверьте, появилась ли запись в таблице лога**:

```sql
SELECT * FROM AlertLog_Фамилия.dbo.ErrorLog;
```

5.5. **Сделайте скриншот** срабатывания (строка в таблице лога, увеличение `occurrence_count`).
