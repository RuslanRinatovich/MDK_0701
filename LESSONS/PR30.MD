# 🧪 Практическая работа №30  
## Создание задания полностью через T-SQL

⏱️ **Продолжительность:** 90 минут  
🎯 **Цель работы:**  
Научиться создавать задания SQL Server Agent с помощью системных хранимых процедур без использования графического интерфейса, настраивать шаги, расписания и уведомления программно, а также управлять заданиями через T-SQL.

🖥️ **Оборудование:**  
Виртуальная машина с Windows Server / Windows 10, установленными SQL Server Developer Edition и SSMS.

---

## 🧠 Глубокое погружение: перед началом

В этой работе вы полностью откажетесь от графического интерфейса и создадите задание с помощью T-SQL. Это позволит вам:
- Автоматизировать развёртывание заданий на многих серверах
- Хранить определения заданий в системе контроля версий (Git)
- Легко восстанавливать задания после переустановки сервера

### 🔹 Этап 2. Создание простого задания с одним шагом (15 мин)

2.1. **Напишите скрипт для создания задания, которое вставляет запись в лог:**

```sql
USE msdb;
GO

DECLARE @jobId BINARY(16);

-- 1. Создание задания
EXEC dbo.sp_add_job
    @job_name = N'LogJob_Фамилия',
    @enabled = 1,
    @description = N'Задание для записи в лог',
    @owner_login_name = N'sa',
    @job_id = @jobId OUTPUT;

-- 2. Добавление шага
EXEC dbo.sp_add_jobstep
    @job_id = @jobId,
    @step_name = N'Insert Log Entry',
    @subsystem = N'TSQL',
    @command = N'
        INSERT INTO TSQLJobPractice_Фамилия.dbo.Log (Message)
        VALUES (''Задание выполнено в '' + CONVERT(NVARCHAR, GETDATE(), 120));
    ',
    @database_name = N'TSQLJobPractice_Фамилия',
    @on_success_action = 3,  -- завершить успешно
    @on_fail_action = 4;     -- завершить с ошибкой

-- 3. Добавление на сервер
EXEC dbo.sp_add_jobserver
    @job_name = N'LogJob_Фамилия';

PRINT 'Задание LogJob_Фамилия создано';
```

2.2. **Запустите задание вручную:**

```sql
EXEC msdb.dbo.sp_start_job @job_name = N'LogJob_Фамилия';
```


### 🔹 Этап 3. Создание задания с несколькими шагами и расписанием (20 мин)

3.1. **Создайте задание для бэкапа с проверкой и очисткой:**

```sql
USE msdb;
GO

DECLARE @jobId BINARY(16);
DECLARE @CommandBackup NVARCHAR(MAX);
DECLARE @CommandCleanup NVARCHAR(MAX);

-- Динамическое имя файла
SET @CommandBackup = '
    DECLARE @FileName NVARCHAR(500);
    SET @FileName = ''C:\Backup\ПР30\TSQLJobPractice_Фамилия_'' + FORMAT(GETDATE(), ''yyyyMMdd_HHmm'') + ''.bak'';
    BACKUP DATABASE [TSQLJobPractice_Фамилия]
    TO DISK = @FileName
    WITH COMPRESSION, CHECKSUM, STATS = 10;
    PRINT ''Бэкап завершён: '' + @FileName;
';

SET @CommandCleanup = '
    EXEC xp_cmdshell ''forfiles /p "C:\Backup\ПР30" /m *.bak /d -7 /c "cmd /c del @file"'';
    PRINT ''Очистка старых бэкапов выполнена'';
';

-- Создание задания
EXEC dbo.sp_add_job
    @job_name = N'BackupJob_Фамилия',
    @enabled = 1,
    @description = N'Ежедневный бэкап и очистка',
    @owner_login_name = N'sa',
    @job_id = @jobId OUTPUT;

-- Шаг 1: Бэкап
EXEC dbo.sp_add_jobstep
    @job_id = @jobId,
    @step_name = N'Backup Database',
    @subsystem = N'TSQL',
    @command = @CommandBackup,
    @database_name = N'master',
    @on_success_action = 1,   -- перейти к следующему шагу
    @on_fail_action = 4,      -- ошибка
    @retry_attempts = 2,
    @retry_interval = 5;

-- Шаг 2: Очистка старых бэкапов
EXEC dbo.sp_add_jobstep
    @job_id = @jobId,
    @step_name = N'Cleanup Old Backups',
    @subsystem = N'CmdExec',
    @command = @CommandCleanup,
    @on_success_action = 3,   -- завершить успешно
    @on_fail_action = 3;      -- всё равно завершить успешно (очистка не критична)

-- Расписание: ежедневно в 03:00
EXEC dbo.sp_add_schedule
    @schedule_name = N'Daily_3AM',
    @freq_type = 4,              -- ежедневно
    @freq_interval = 1,          -- каждый день
    @active_start_time = 30000,  -- 03:00
    @active_end_time = 235959,
    @active_start_date = 20260501,
    @active_end_date = 99991231;

-- Привязка расписания
EXEC dbo.sp_attach_schedule
    @job_name = N'BackupJob_Фамилия',
    @schedule_name = N'Daily_3AM';

-- Добавление на сервер
EXEC dbo.sp_add_jobserver
    @job_name = N'BackupJob_Фамилия';

PRINT 'Задание BackupJob_Фамилия создано с расписанием Daily_3AM';
```

3.2. **Запустите задание вручную:**

```sql
EXEC msdb.dbo.sp_start_job @job_name = N'BackupJob_Фамилия';
```

3.3. **Проверьте историю выполнения:**

```sql
SELECT 
    j.name,
    jh.run_date,
    jh.run_time,
    CASE jh.run_status
        WHEN 0 THEN '❌ Ошибка'
        WHEN 1 THEN '✅ Успех'
        WHEN 2 THEN '🔄 Повтор'
        WHEN 3 THEN '⏹️ Отменён'
        WHEN 4 THEN '⏳ Выполняется'
    END AS Status,
    jh.message
FROM msdb.dbo.sysjobs j
JOIN msdb.dbo.sysjobhistory jh ON j.job_id = jh.job_id
WHERE j.name = 'BackupJob_Фамилия'
ORDER BY jh.run_date DESC, jh.run_time DESC;
```

### 🔹 Этап 4. Динамическое создание заданий для всех пользовательских баз (20 мин)

4.1. **Напишите скрипт, который создаёт задание бэкапа для каждой пользовательской базы:**

```sql
USE msdb;
GO

DECLARE @dbName NVARCHAR(128);
DECLARE @jobId BINARY(16);
DECLARE @jobName NVARCHAR(255);
DECLARE @stepCommand NVARCHAR(MAX);

DECLARE db_cursor CURSOR FOR
    SELECT name FROM sys.databases
    WHERE database_id > 4 AND state_desc = 'ONLINE'
        AND name NOT IN ('tempdb')
        AND name LIKE '%Фамилия%';  -- ограничим нашими базами

OPEN db_cursor;
FETCH NEXT FROM db_cursor INTO @dbName;

WHILE @@FETCH_STATUS = 0
BEGIN
    SET @jobName = N'Backup_' + @dbName;
    
    IF NOT EXISTS (SELECT 1 FROM msdb.dbo.sysjobs WHERE name = @jobName)
    BEGIN
        SET @stepCommand = N'
            DECLARE @FileName NVARCHAR(500);
            SET @FileName = ''C:\Backup\ПР30\' + @dbName + N'_'' + FORMAT(GETDATE(), ''yyyyMMdd_HHmm'') + ''.bak'';
            BACKUP DATABASE [' + @dbName + N'] TO DISK = @FileName
            WITH COMPRESSION, CHECKSUM, STATS = 10;
        ';
        
        EXEC dbo.sp_add_job
            @job_name = @jobName,
            @enabled = 1,
            @description = N'Автоматический бэкап базы ' + @dbName,
            @owner_login_name = N'sa',
            @job_id = @jobId OUTPUT;
        
        EXEC dbo.sp_add_jobstep
            @job_id = @jobId,
            @step_name = N'Backup Step',
            @subsystem = N'TSQL',
            @command = @stepCommand,
            @database_name = N'master',
            @on_success_action = 3,
            @on_fail_action = 4;
        
        EXEC dbo.sp_add_jobserver
            @job_name = @jobName;
        
        PRINT 'Создано задание: ' + @jobName;
    END
    
    FETCH NEXT FROM db_cursor INTO @dbName;
END

CLOSE db_cursor;
DEALLOCATE db_cursor;
```

4.2. **Проверьте, какие задания были созданы:**

```sql

FROM msdb.dbo.sysjobs
WHERE name LIKE 'Backup_%_Фамилия%'
ORDER BY name;
```

6.4. **Создайте сводный отчёт по всем заданиям:**

```sql
SELECT 
    j.name,
    j.enabled,
    j.date_created,
    COUNT(js.step_id) AS StepCount,
    CASE WHEN s.schedule_id IS NOT NULL THEN 'Yes' ELSE 'No' END AS HasSchedule
FROM msdb.dbo.sysjobs j
LEFT JOIN msdb.dbo.sysjobsteps js ON j.job_id = js.job_id
LEFT JOIN msdb.dbo.sysjobschedules jsched ON j.job_id = jsched.job_id
LEFT JOIN msdb.dbo.sysschedules s ON jsched.schedule_id = s.schedule_id
WHERE j.name LIKE '%Фамилия%'
GROUP BY j.name, j.enabled, j.date_created, s.schedule_id
ORDER BY j.name;
```
